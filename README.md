# 页面朗读助手

将网页文字转换为语音播放的 Chrome 扩展。

## 功能特点

- **悬浮工具条** - 页面底部可折叠的悬浮控制面板，不遮挡页面内容
- **智能内容提取** - 自动识别页面主内容区域，过滤导航栏和侧边栏
- **段落导航** - 将页面内容分割为可管理的段落，支持上一段/下一段切换
- **点击定位** - 点击朗读列表中的任意段落，页面会自动滚动并高亮对应位置
- **语音设置** - 支持调节语速、音调，选择不同语音
- **动态页面支持** - 支持 docsify 等动态加载的内容

## 安装方法

1. 下载/克隆本仓库
2. 打开 Chrome，进入 `chrome://extensions`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本仓库文件夹

## 使用方法

1. 安装扩展后，访问任意网页
2. 点击页面底部的 📖 按钮展开工具条
3. 点击「播放」按钮开始朗读
4. 使用「上一段」「下一段」按钮导航
5. 点击朗读列表中的任意段落，可跳转并高亮对应位置

## 快捷操作

| 操作 | 说明 |
|------|------|
| 点击预览区域 | 滚动到当前朗读段落并高亮 |
| 点击朗读列表项 | 跳转页面并开始朗读该段落 |
| 调整语速滑块 | 实时改变朗读速度 |

## 技术原理

使用浏览器原生 Web Speech API，无需联网，通过 `speechSynthesis` 实现文字转语音。

内容提取使用 TreeWalker API 遍历 DOM，配合 MutationObserver 监听动态内容变化。
